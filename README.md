# minesolver 扫雷棋盘求解助手

终端里的扫雷小助手：读入一个扫雷棋盘，用**确定性逻辑**算出哪些格子一定安全、哪些一定是雷。纯 Python 标准库，无依赖。

## 棋盘格式

文本文件（或 stdin），每行等长：

- `0-8`：已翻开的数字
- `.`：未翻开的格子
- `F`：已标记的旗子

示例 `board.txt`：

```
.....
121..
```

## 用法

```bash
python -m minesolver board.txt        # 分析棋盘
python -m minesolver --guess board.txt  # 无确定走法时给一个猜测建议
cat board.txt | python -m minesolver    # 从 stdin 读
```

输出示例：

```
棋盘 2x5，分析结果：

XSXS.
121S.

安全格（3）：(1, 2), (1, 4), (2, 4)
必雷（2）：(1, 1), (1, 3)
```

坐标是 **1-based**（第 1 行第 1 列），方便对照着点。

## 求解逻辑

1. **基础规则**：数字 N，相邻旗子 f 个、未翻开邻格 h 个
   - `N - f == 0` → h 全是安全格
   - `N - f == len(h)` → h 全是雷
2. **子集规则**：若数字 A 的未翻开邻格集合是 B 的真子集，则差集上的雷数 = B 剩余雷数 − A 剩余雷数；差集雷数为 0 → 全安全，等于差集大小 → 全是雷。**经典 1-2-1 模式是子集规则的特例**，本工具直接覆盖。
3. **约束传播**：把已判定的安全格/雷折回所有约束，迭代到不动点（链式推理）。
4. `--guess`：实在没有确定走法时，给每个前沿未翻开格估算 `p = max(相邻数字的 剩余雷数/未翻开邻格数)`，推荐 p 最小的；猜测**不会**指向已判定的雷或安全格。

## 真实验证

- `py_compile` 通过（Python 3.12）
- 手工棋盘断言：纯 1-2-1 模式推出两端雷 + 中间安全；扩展 1-2-1 经传播推出全部结论；全雷/旗子/无结论/矛盾棋盘/非法字符/空棋盘/不等长行，全部符合预期
- 修复过的 bug：`--guess` 曾返回已判定为雷的格子（回退分支没排除已知结论），已修复并加断言
- CLI 端到端：文件参数、stdin、`--guess` 均正常

## 已知限制（诚实版）

- **只有确定性逻辑，没有完整 CSP/暴力搜索**：需要枚举猜测才能解的棋盘，本工具只能给启发式猜测，不保证最优
- `--guess` 的概率是粗略估计（各约束独立假设），不是精确概率
- 不直接玩扫雷游戏，只分析你贴进来的棋盘文本；不支持扫雷变体规则
- 需要 Python 3.10+

## 创意点

把扫雷老玩家的"1-2-1"经验法则还原成它的数学本质（子集规则），再配上约束传播做链式推理——一个 200 行的小工具，讲清楚了确定性扫雷求解的全部套路。
